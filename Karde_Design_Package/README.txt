03_PNG_Previews/
  Same 11 screens rendered as PNG, for quick viewing in apps that don't
  open SVG directly. The SVGs are the source files — open those in Figma,
  Illustrator, or a browser for full vector quality and to extract exact
  colors/measurements for Flutter implementation.

Start with Karde_Branding_Guide.md — it explains the reasoning behind every
color, font, and layout decision, plus implementation notes for Flutter.
